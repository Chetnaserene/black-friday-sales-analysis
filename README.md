# Black Friday Sales Data Analysis

## Overview
This project analyzes a Black Friday sales dataset to understand consumer purchasing behavior. The dataset (`train.csv`) contains information about customers, their demographics, and purchase details. The provided **Google Colab notebook** (`BlackFridaySales.ipynb`) preprocesses the data, handles missing values, and encodes categorical variables to prepare the dataset for further analysis or modeling.

## Dataset
The dataset (`train.csv`) includes the following columns:
- **User_ID**: Unique identifier for each customer.
- **Product_ID**: Unique identifier for each product.
- **Gender**: Customer's gender (M/F).
- **Age**: Customer's age group (e.g., 0-17, 18-25, etc.).
- **Occupation**: Customer's occupation code.
- **City_Category**: City category (A, B, C).
- **Stay_In_Current_City_Years**: Years the customer has stayed in the current city.
- **Marital_Status**: Marital status (0 or 1).
- **Product_Category_1**: Primary product category.
- **Product_Category_2**: Secondary product category (may contain missing values).
- **Product_Category_3**: Tertiary product category (may contain missing values).
- **Purchase**: Purchase amount in dollars.

## Project Structure
- `BlackFridaySales.ipynb`: Google Colab Notebook containing the data preprocessing and analysis steps.
- `train.csv`: Input dataset (not included in the repository; users must provide their own copy).
- `BlackFriday_Processed.csv`: Output dataset after preprocessing (generated by the notebook).
- `README.md`: This file, providing an overview of the project.

## Output
- The notebook generates `BlackFriday_Processed.csv`, which contains the cleaned dataset with encoded variables.

## Steps in the Notebook
1. **Import Libraries**: Loads required libraries.
2. **Load Dataset**: Reads `train.csv` into a pandas DataFrame.
3. **Inspect Data**: Displays general dataset info and sample data.
4. **Handle Missing Values**: Fills missing `Product_Category_2` and `Product_Category_3` with 'Unknown'.
5. **Data Preprocessing**: Encodes categorical variables using `LabelEncoder`.
6. **Save Output**: Exports processed data to `BlackFriday_Processed.csv`.
